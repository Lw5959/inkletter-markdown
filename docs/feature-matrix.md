# Typora 1.14.17 功能对照

目标版本固定为 Typora 1.14.17。范围来自稳定版发行说明、用户手册和单项功能说明。本机已安装的 Typora 为 1.8.10，1.14.17 的实机逐项复核仍待完成。[稳定版发行记录](https://typora.io/releases/stable) · [Markdown 参考](https://support.typora.io/Markdown-Reference/) · [功能手册](https://support.typora.io/)

状态中的「macOS 验收」表示在实际 Tauri/WKWebView 发布配置中走过该流程。「自动化」表示有单元测试或浏览器操作证据。「已接入」表示实现可从应用进入，仍有专项或平台验证待做。
